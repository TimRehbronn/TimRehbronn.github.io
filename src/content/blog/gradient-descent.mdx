## The idea

To minimise a function $f(x)$, gradient descent repeatedly takes a small step
against the slope:

$$
x_{t+1} = x_t - \eta \, f'(x_t)
$$

The **learning rate** $\eta$ decides how big each step is. Here we use the non-convex function

$$
f(x) = \tfrac{1}{4}x^4 - x^2 + 0.35\,x,
$$

which has a shallow local minimum on the right and a deeper global minimum on the left.

A few things to try:

- With a **small** $\eta$ the ball creeps down and gets stuck in the nearest (local) minimum.
- With a **medium** $\eta$ the first step overshoots the bump and lands in the global minimum.
- With a **large** $\eta$ the iterates oscillate and eventually diverge.

## In code

```python
def gradient_descent(df, x0, lr=0.05, steps=100):
    x = x0
    for _ in range(steps):
        x = x - lr * df(x)
    return x
```
